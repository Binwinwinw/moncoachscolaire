# Section Collège — README

Ce dossier contient les pages et ressources pédagogiques destinées aux niveaux de la classe de 6ème, 5ème, 4ème et 3ème.

Structure :

- `index.php` — page d'accueil de la section Collège
- `6eme/guide-remediation.php` — guide complet de remédiation pour la 6ème
- `6eme/exercices-6eme.php` — exercices progressifs pour la 6ème
- `5eme/guide-remediation.php` — guide complet de remédiation pour la 5ème
- `5eme/exercices-5eme.php` — exercices progressifs pour la 5ème
- `4eme/guide-remediation.php` — guide complet de remédiation pour la 4ème
- `4eme/exercices-4eme.php` — exercices progressifs pour la 4ème
- `3eme/guide-remediation.php` — guide complet de remédiation pour la 3ème
- `3eme/exercices-3eme.php` — exercices progressifs pour la 3ème

Usage : parcourir les guides depuis `college/index.php` ou lier directement une fiche/exercice depuis la navigation principale.

Contributions : suivre le format existant (inclure `header.php` / `footer.php`) et ajouter des tests dans `tests/test_college_pages.php` pour toute nouvelle page ajoutée.
