# Section BAC — README

Ce dossier contient les pages et ressources pédagogiques destinées aux niveaux du lycée : Seconde, Première et Terminale.

Structure :

- `index.php` — page d'accueil de la section BAC
- `bac/guide-remediation.php` — guide complet de remédiation pour le BAC
- `bac/exercices-bac.php` — exercices progressifs pour le BAC

Usage : parcourir les guides depuis `bac/index.php` ou lier directement une fiche/exercice depuis la navigation principale.

Contributions : suivre le format existant (inclure `header.php` / `footer.php`) et ajouter des tests dans `tests/test_bac_pages.php` pour toute nouvelle page ajoutée.
