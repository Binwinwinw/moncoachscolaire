# Section Lycée — README

Ce dossier contient les pages et ressources pédagogiques destinées aux niveaux du lycée : Seconde, Première et Terminale.

Structure :

- `index.php` — page d'accueil de la section Lycée+
- `2nde/guide-remediation.php` — guide complet de remédiation pour la Seconde
- `2nde/exercices-2nde.php` — exercices progressifs pour la Seconde
- `1ere/guide-remediation.php` — guide complet pour la Première
- `1ere/exercices-premiere.php` — exercices pour la Première
- `terminale/guide-remediation.php` — guide et préparation Bac pour la Terminale
- `terminale/exercices-terminale.php` — annales et exercices Terminale

Usage : parcourir les guides depuis `lycee/index.php` ou lier directement une fiche/exercice depuis la navigation principale.

Contributions : suivre le format existant (inclure `header.php` / `footer.php`) et ajouter des tests dans `tests/test_lycee_pages.php` pour toute nouvelle page ajoutée.
