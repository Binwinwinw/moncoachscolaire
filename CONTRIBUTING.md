# CONTRIBUTING

Merci de contribuer à MonCoachScolaire !

## Comment contribuer

- Ouvrez une issue pour signaler un bug ou suggérer une amélioration.
- Proposez une pull request pour toute modification de code ou de documentation.
- Respectez les conventions de code : PHP (PSR-12), Tailwind CSS, Vanilla JS (voir ci-dessous).
- Suivez la structure du projet : pages dans `src/pages/`, composants dans `src/components/`, includes partagés dans `src/includes/`.

## Processus de revue

- Chaque contribution est relue par un mainteneur.
- Les tests (Playwright, lint PHP) doivent passer avant fusion.

## Ressources utiles

- Lire `.github/copilot-instructions.md` pour les conventions, automatisation et architecture.
- Voir `dev/JOURNAL_REPRISE.md` et `dev/SUIVI_BUGS_AMELIORATIONS.md` pour l’historique et les priorités.
- Consulter `README.md` et `DOCUMENTATION.md` pour la prise en main technique.
