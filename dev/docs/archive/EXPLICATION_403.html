🔧 Erreurs 403 sur Dashboard Admin - EXPLICATION ET SOLUTION

❓ Quel est le problème ?

Tu vois ces erreurs :

Erreur lors du chargement des statistiques: Erreur HTTP 403
Erreur chargement qualité: Erreur HTTP 403
Erreur lors du chargement des utilisateurs: Erreur HTTP 403
Erreur lors du chargement des logs: Erreur HTTP 403

C'est normal ! Le code 403 signifie "Accès refusé". Les APIs demandent une authentification admin.

✅ Solution: Se connecter en tant qu'admin

Les erreurs 403 disparaîtront une fois que tu seras connecté en tant qu'administrateur.

Étape 1 : Créer ou trouver un compte admin

Dans la base de données, tu dois avoir un utilisateur avec le rôle admin.

Admin existant: zinzin

Si tu dois en créer un:

INSERT INTO Users (Username, Email, PasswordHash, Role) 
VALUES ('admin', 'admin@example.com', '$2y$10$[hash]', 'admin');

Étape 2 : Te connecter

  1. Va sur la page de login: /public/index.php?page=login
  2. Connecte-toi avec ton compte admin (ex: zinzin)
  3. Tu devrais voir un cookie PHPSESSID créé dans le navigateur

Étape 3 : Accéder au Dashboard Admin

  1. Va sur: /public/index.php?page=dashboard_admin
  2. Le JavaScript va automatiquement appeler les APIs avec ta session admin
  3. Les erreurs 403 devraient disparaître
  4. Tu verras les données: statistiques, utilisateurs, logs, etc.

🔐 Pourquoi il y a une authentification ?

  • Sécurité : Les APIs admin contiennent des données sensibles
  • Confidentialité : Seul un admin peut voir les stats, utilisateurs, logs
  • Contrôle d'accès : Évite les attaques par accès non autorisé

📋 Checklist de Troubleshooting

✅ Si tu es connecté en admin:

  • Les erreurs 403 disparaissent
  • Les API retournent les données correctement
  • Tout devrait fonctionner normalement

⚠️ Si tu as TOUJOURS des erreurs 403 même en étant admin:

  • Vérifier que la session PHP est active (F12 → Application → Cookies → PHPSESSID)
  • Vérifier que le fichier api_proxy.php existe
  • Vérifier que le fichier .htaccess n'a pas été modifié
  • Tester les APIs directement: /api/admin/stats.php (doit retourner JSON)

🧪 Test rapide (sans connexion)

Pour tester l'API directement (sans avoir à se connecter), tu peux :

  1. Consulter : test_api_admin.html
  2. Cela montre le statut HTTP de chaque API
  3. Si tu vois 403, c'est l'authentification qui manque

📚 Fichiers impliqués

  • src/pages/dashboard_admin.php - Page principale du dashboard
  • public/assets/js/admin-dashboard.js - JavaScript qui appelle les APIs
  • src/api/admin/*.php - Endpoints API (stats, users, logs, etc.)
  • src/includes/admin_auth.php - Système d'authentification
  • api_proxy.php - Routeur pour les APIs en production
  • .htaccess - Règles de routage

💡 En Résumé

Les erreurs 403 sont ATTENDUES si tu n'es pas admin !

C'est un mécanisme de sécurité. Connecte-toi en tant qu'admin et le problème sera résolu.
