## 📚 Philosophie pédagogique

### Principe : Cours → Exercices → Pratique

```
1. COURS interactif        2. EXERCICES guidés      3. PRATIQUE autonome
   └─ Explications           └─ Application           └─ Consolidation
   └─ Exemples visuels       └─ Corrections           └─ Évaluation
   └─ Méthodes               └─ Points clés           └─ Progression
```

## 🎨 Principes de création de cours

### 1. Visuel et interactif

✅ **Schémas ASCII** pour illustration rapide  
✅ **Tableaux comparatifs** pour clarifier  
✅ **Exemples concrets** du quotidien  
✅ **Analogies** pour faciliter la compréhension

### 2. Progressivité

```
Niveau 1 : Découverte (exemples simples)
    ↓
Niveau 2 : Compréhension (théorie)
    ↓
Niveau 3 : Application (méthode)
    ↓
Niveau 4 : Maîtrise (exercices)
```

### 3. Multi-supports

📖 **Texte** : Explications claires et structurées  
🎬 **Vidéos** : Liens vers contenus de qualité  
🎮 **Interactif** : Exercices intégrés  
📊 **Visuel** : Schémas, tableaux, graphiques

### 4. Liens bidirectionnels

Chaque **cours** renvoie vers ses **exercices**  
Chaque **exercice** renvoie vers son **cours**
