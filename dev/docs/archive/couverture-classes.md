## 🎯 Objectifs Prioritaires

Pour une couverture complète du collège et lycée, il faudrait créer :

1. **Collège 5ème** : Math + Français (priorité moyenne)
2. **Collège 4ème** : Math + Français (priorité moyenne)
3. **Collège 3ème** : Français (priorité haute - préparation DNB)
4. **Lycée Seconde** : Français (priorité haute)
5. **Lycée Première** : Mathématiques (priorité haute - préparation BAC)
6. **Lycée Terminale** : Math + Français (priorité haute - préparation BAC)

## 💡 Recommandation

Concentrer d'abord sur les classes à examens (3ème, Première, Terminale) avant d'étendre aux autres niveaux.
