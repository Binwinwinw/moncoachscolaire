**Niveau** : 6ème

Aire du rectangle : 4 × 3 = 12 cm²
Aire totale : 16 + 12 = 28 cm²

**Réponse attendue** :

#### Exercice 2 : Théorème de Pythagore
**Matière** : Mathématiques  
**Niveau** : 4ème  
**Type** : Géométrie

**Contenu** :
Un triangle rectangle a des côtés de 3 cm et 4 cm. Quelle est la longueur de l'hypoténuse ?

**Réponse attendue** :
D'après le théorème de Pythagore : a² + b² = c²
3² + 4² = 9 + 16 = 25
Donc c = √25 = 5 cm

#### Exercice 3 : Statistiques

**Réponse attendue** :

#### Exercice 4 : Factorisation (source : Khan Academy adapté)
**Matière** : Mathématiques  
**Niveau** : 4ème  
**Type** : Calcul

**Contenu** :
Factorise : 6x + 9

**Réponse attendue** :
6x + 9 = 3(2x + 3)

#### Exercice 5 : Résolution d'équations avec fractions (source : CK-12 adapté)
**Matière** : Mathématiques  
**Niveau** : 4ème  
**Type** : Équation

**Contenu** :
Résous l'équation : (x/2) + 3 = 7

**Réponse attendue** :
x/2 + 3 = 7
x/2 = 7 - 3
x/2 = 4
x = 4 × 2
x = 8

#### Exercice 6 : Théorème de Thalès (source : Desmos adapté)
**Matière** : Mathématiques  
**Niveau** : 4ème  
**Type** : Géométrie

**Contenu** :
Dans un triangle ABC, on trace une droite parallèle à BC qui coupe AB en D et AC en E. Si AD = 3 cm, DB = 2 cm et AE = 4,5 cm, calcule EC.

**Réponse attendue** :
D'après le théorème de Thalès : AD/AB = AE/AC
3/5 = 4,5/(4,5 + EC)
3(4,5 + EC) = 4,5 × 5
13,5 + 3EC = 22,5
3EC = 9
EC = 3 cm

#### Exercice 2 : Système d'équations
**Matière** : Mathématiques  
**Niveau** : 3ème  
**Type** : Équation

**Contenu** :
Résous le système :
{ x + y = 10
{ x - y = 2

**Réponse attendue** :
En additionnant les deux équations : 2x = 12, donc x = 6
En remplaçant : 6 + y = 10, donc y = 4
Solution : x = 6, y = 4

#### Exercice 3 : Trigonométrie
**Matière** : Mathématiques  
**Niveau** : 3ème  
**Type** : Calcul

**Contenu** :
Dans un triangle rectangle, si l'angle est de 30° et le côté adjacent mesure 6 cm, calcule la longueur de l'hypoténuse en utilisant cos(30°).

**Réponse attendue** :
cos(30°) = côté adjacent / hypoténuse
√3/2 = 6 / hypoténuse
hypoténuse = 6 / (√3/2) = 12/√3 = 4√3 cm
