# Guide d'installation de la page de test des exercices

1. Vérifier que dev/tools/tests/exercise_test_page.php existe (ne pas dupliquer dans views/)
2. La route ?page=test_exercises est déjà ajoutée dans public/index.php
3. Accéder à la page via /public/index.php?page=test_exercises
4. Valider l’affichage et l’absence d’erreur JS
5. Voir README.md pour les conventions tests.
