# Dossier Images

## Image de fond de la landing page

Pour télécharger l'image de fond (jeune lisant un livre) :

1. **URL de l'image Unsplash (libre de droits)** :
   https://images.unsplash.com/photo-1481627834876-b7833e8f5570?ixlib=rb-4.0.3&auto=format&fit=crop&w=1974&q=80

2. **Nom du fichier** : `young-person-reading.jpg`

3. **Instructions** :
   - Ouvrez le lien ci-dessus dans votre navigateur
   - Faites un clic droit sur l'image → "Enregistrer l'image sous..."
   - Enregistrez-la dans ce dossier (`img/`) avec le nom `young-person-reading.jpg`

**Alternative** : Vous pouvez utiliser n'importe quelle autre image d'un jeune lisant un livre, tant qu'elle est libre de droits et nommée `young-person-reading.jpg`
